## My course's exact conventions — follow these, do not substitute standard textbook ones

1. **8-queens representation.** A chromosome is n digits. Position in the string = column, digit value = the row of that column's queen. So `24748552` means column 1's queen is in row 2, column 2's is in row 4, etc.
2. **Fitness = the number of NON-ATTACKING pairs**, not attacking pairs. Higher is better. Max for 8 queens = C(8,2) = 28; general form n(n−1)/2.
3. **Diagonal test**: two queens attack when |Δcolumn| = |Δrow|. Queens can never share a column under this encoding.
4. **Negative fitness is clamped to 0.** A chromosome whose f(x) computes negative is recorded as 0, gets probability 0, and receives **no bin on the roulette wheel** — it can never be selected.
5. **Selection method examined is roulette wheel**: probability = fᵢ/Σf, stacked into cumulative bins, then a random number in [0,1] picks the bin.
6. **GA definition to be quoted**: "a variant of stochastic beam search in which successor states are generated by combining two parent states rather than by modifying a single state."
7. **Column/row index origin varies** — some of my lecture exercises number from 0, the board diagrams from 1. State the convention in every question you write.
